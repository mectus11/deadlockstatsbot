The match card

A card after every game

Posted the moment the match settles, with the build, the numbers and the company you kept.

  • The headlineResult, hero portrait, mode, duration and your Steam avatar on one brass-framed plate.
  • The numbersK/D/A, net worth, last hits, denies and a grid of combat stats from hero damage to accuracy.
  • The buildEvery shop item in purchase order, with its real icon and a slot-coloured outline.
  • The partyWho you queued with, their heroes and scorelines. Hidden entirely when you run solo.
  • Rank, when configuredPP score, rank badge and lobby averages from Statlocker. Without a key the card simply leaves them out.

Commands

Everything is a slash command

No prefix, no menus to learn. Pick the command and the card comes back.

For players

  • /linkLink Steam and turn on automatic match posts.
  • /saveSave an account without auto-posting.
  • /statsCareer card for you, or for any Steam ID.
  • /latestmatchThe full card for your latest game.
  • /matchesYour last ten games at a glance.
  • /pause /resumeStop or restart posts. Resuming skips the backlog.
  • /unlinkForget the account and stop its posts.
  • /helpThe short version of this page.

For admins

  • /setchannelChoose the channel for match cards.
  • /settings showSee where each feature posts.
  • /settings channelGive patch notes their own channel, or fall back to the match one.
  • /patchnotesPost the latest Steam patch notes on demand.
  • /statusUptime, poll results and Deadlock API health.
  • /inviteSend the bot to another server.

Right-click a user for Deadlock stats, or a message containing a Steam ID for Deadlock lookup. Every match card has a Refresh button that re-renders it once the item data lands.

Where the numbers come from

Matches and art

deadlock-api.com, no key needed. Match data, hero and item names, and every picture, downloaded once and cached locally.

Rank and PP

The Statlocker API with your own key. Without it the cards leave rank out; cards that use it carry the required “Powered by Statlocker” line.

Built with AI

Code, card renderer and documentation made with Claude and OpenCode, directed and tested on a live Discord server.

Setup

Running in four steps

Windows is the cosy path; anywhere with Python 3.10+ works the same.

  1. Create the application

    Make a bot at discord.com/developers/applications, then invite it with the bot and applications.commands scopes plus Send Messages and Attach Files.

  2. Add the token

    Copy .env.example to .env and paste the bot token.

    DISCORD_TOKEN=your-bot-token
  3. Start it

    Double-click run.bat, or install and run it yourself:

    pip install -r requirements.txt
python bot.py
  4. Wire up the server

    Run /save for immediate stats. An admin sets the channel with /setchannel, and anyone who wants automatic cards uses /link instead.
